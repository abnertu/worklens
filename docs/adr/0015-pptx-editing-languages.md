# ADR-0015: PPTX 文字的編輯語言

## Status

Accepted — 2026-11-16

## Context

WorkLens 原先只寫文字與選填的樣式格式。
PowerPoint 不會從這些文字繼承 placeholder 的編輯語言。
選取自動產生的中文時，字型欄因此顯示拉丁字型。
手動輸入的文字則具有獨立的中英文語言標記。

## Decision

1. 從投影片所用母片取得既有的中文與英文語言配對。
2. 依中文與拉丁字元邊界分開文字片段。
3. 將配對的語言寫入片段的 `lang` 與 `altLang`。
4. 保留文字、樣式、連結與既有的語言標記。

沒有中英文語言配對時，不推測語言。
其他文字系統不新增語言標記。
Unicode 組合字與代理對不可拆開。
字型名稱仍由模板決定。
IR 與 schema 不新增欄位。

## Consequences

Run 可以只有語言屬性，而沒有格式覆寫。
這項規則也適用 1.0 manifest，補充 [ADR-0006](0006-pptx-open-xml-sdk.md)。
PowerPoint 驗證須分別選取自動產生的中文與英文。
只檢查新輸入文字或主題字型不足以驗證這項行為。
