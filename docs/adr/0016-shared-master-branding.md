# ADR-0016: 輸出母片的共用品牌

## Status

Accepted — 2026-11-16

## Context

逐頁寫入的頁尾與 Logo 不會出現在手動新增的投影片。
乾淨模板也不應保存報告的年月或個人資料。
使用者希望自行新增頁面時自動取得相同品牌內容。

## Decision

1. 以選填的 `shared_brand.masters` 宣告母片與一般圖形名稱。
2. 在輸出副本的母片寫入共用頁尾與 Logo。
3. 保留原生頁碼欄位與封面的單位名稱欄位。
4. 對母片文字套用 ADR-0015 的編輯語言規則。

每個名稱必須精確且唯一。
所有使用該母片的版面必須顯示母片圖形。
同一版面不得再宣告逐頁 Logo。
缺少、重複、衝突或沒有有效位置的目標會使渲染失敗。
沒有宣告時，保留既有 manifest 的行為。
來源模板與主題字型保持不變。

## Consequences

手動新增的投影片會繼承輸出母片的共用內容。
編輯共用內容時只需修改輸出母片。
隱藏背景圖形仍會隱藏這些共用內容。
未指定 Logo 時，共用位置保持空白。
本次月報不嵌入 Logo，也不追蹤本機動態素材。
